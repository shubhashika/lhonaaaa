# European Escapes - Vacation Destinations Gallery

A beautiful, interactive gallery website showcasing the most stunning destinations across Europe.

## 🌍 About

European Escapes is a professional art gallery-style website featuring 24 of Europe's most iconic vacation destinations organized by country:

- **Italy** (6 destinations): Venice, Florence, Amalfi Coast, Milan, Lake Como, Cinque Terre
- **France** (6 destinations): Paris, Provence, Côte d'Azur, Mont-Saint-Michel, Loire Valley, Versailles
- **Rome** (6 landmarks): Colosseum, Vatican City, Roman Forum, Trevi Fountain, Pantheon, Spanish Steps
- **Switzerland** (6 destinations): Zermatt, Interlaken, Lucerne, Jungfrau Region, Zurich, Swiss Alps

## 🚀 How to Use

1. **Extract the folder** from the zip file
2. **Open `index.html`** in any web browser (no server required)
3. **Click on a country card** to view all destinations in that country
4. **Browse the gallery** - hover over destination cards to see beautiful animations
5. **Click the back button** to return to the country selection

## 🛠️ Customization

The website is easy to customize:

- **Change colors**: Edit the gradient colors in the `<style>` section
- **Add more destinations**: Add new entries to the JavaScript `destinations` object
- **Update images**: Replace SVG files in the `images/` folder with new artwork
- **Modify text**: Edit destination names and descriptions in the JavaScript data
